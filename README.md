<h1 align="center">STORM INFORMATION</h1>

## **О проекте**
STORM INFORMATION — центр аппаратного мониторинга, глубокой системной диагностики и сбора информации о конфигурации компьютера, операционной системы, драйверов и состояния комплектующих.

## **Происхождение и форки**
Оригинальная разработка в составе экосистемы STORM SOFT.

## **Технологический стек**
- **Языки программирования**: C# (.NET 9.0), C++
- **Интерфейс**: WPF, XAML, Графики телеметрии в реальном времени
- **Сбор данных**: Windows Management Instrumentation (WMI), Win32 API, CPUID/SMBIOS парсеры

## **Ключевые возможности**
- **Глубокий анализ процессора, памяти и видеокарты**: Спецификации, частоты, температуры, тайминги и аппаратные инструкции.
- **Мониторинг накопителей**: Данные SMART, температура, процент износа SSD и скорость работы.
- **Экспорт отчетов**: Сохранение полного системного отчета в текстовом и HTML формате.

## **Поддерживаемые платформы и эмуляторы**
- **Операционные системы**: Windows 10, Windows 11 (x64)

## **Установка и запуск**
1. Скачайте инсталлятор `STORM_INFORMATION_<версия>_Setup.exe` или архив `STORM_INFORMATION_<версия>.zip` из секции **Releases** на GitHub.
2. Запустите программу.
